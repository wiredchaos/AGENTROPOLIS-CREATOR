# CITYFLIGHT Creator Lane

CITYFLIGHT is the governed cinematic-world production lane for AGENTROPOLIS-CREATOR.

## Ownership

- CREATOR owns the skill, prompt contract, scene package, continuity locks, rights ledger, and media QA packet.
- ASBE orchestrates jobs, scene state, PBX handoffs, and production status.
- AGENTROPOLIS-AGENT-MCP controls paid provider execution and secret references.
- Mission Control approves spend and public release.
- Gaming District governs game-facing use and authoritative game data.
- ATG defines mandate, authority, evidence, and receipt semantics.
- AGENTROPOLIS-DEPLOY publishes approved manifests and assets.

## Corridor

```text
human mandate
  -> Creator Prompt Contract
  -> CITYFLIGHT scene contract
  -> rights review
  -> cost estimate
  -> Mission Control approval
  -> ASBE orchestration
  -> Agent MCP execution
  -> seam and media validation
  -> approval receipt
  -> Deploy publication
```

## Upstream Reference

The external `oso95/scroll-world` repository is an MIT-licensed research and implementation reference for frame-locked scene chains and a portable scroll-scrub runtime. It is not a hard runtime dependency and must not become an ungoverned provider or billing authority.
